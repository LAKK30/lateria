# LATERIA 🏰

Концептуальный многостраничный сайт фэнтезийного сервера Hytale. Проект выполнен в эстетике Dark Fantasy с готической архитектурой, багровыми оттенками и атмосферными визуальными эффектами.

![LATERIA — главная страница](preview.png)

### 🔗 Посмотреть проект

**[Открыть сайт](https://lakk30.github.io/lateria/)**

### ✨ Особенности

- Главная страница с атмосферным оформлением
- Раздел государств с подробной информацией
- Система событий и интерактивные фильтры
- Рейтинг игроков и государств
- Игровой магазин с интерактивными элементами
- Страница подключения к серверу
- Адаптивный интерфейс и анимации

### 🛠 Технологии

HTML · CSS · JavaScript
